# KoSe Labs

We're **Kobi** and **Semanu**, two MS AI students building practical AI systems as a small engineering team.

KoSe Labs ships one portfolio project at a time, in fixed sprints of 10–14 days. Every project gets:
- a real dataset and a simple baseline;
- a model measured against that baseline, with honest failure analysis;
- a deployed demo, clean code, tests, CI and full documentation.
